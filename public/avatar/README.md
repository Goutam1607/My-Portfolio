# Avatar files

- `intro.mp4`: your talking 3D avatar video (16:9, plain off-white background).
- `poster.jpg`: the still image shown instantly while the video loads. It is the video's
  **first frame**, so there's no visible jump when the video starts.

To replace them, drop in new files with the **same names**. If you change the video,
also replace `poster.jpg` with the new video's first frame.
